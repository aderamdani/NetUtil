# Screenshots

Drop PNGs here with these exact names (referenced by the root README):

- dashboard.png   — Dashboard
- traceroute.png  — Traceroute (map or timeline view)
- bandwidth.png   — Bandwidth Monitor (with live chart)
- speedtest.png   — Speed Test results

Capture guide:
- Use Cmd+Shift+4 then Space, click the NetUtil window (captures with shadow); or Cmd+Shift+5.
- Keep a consistent window size and one appearance (all light OR all dark).
- Retina (2x) is fine; GitHub scales them down. Export as PNG; optimize if over ~1 MB.
